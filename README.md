## Project status

This repository contains an archival Git import of the com0com SourceForge CVS
repository. The initial imported CVS HEAD snapshot is marked by the
`cvs-head-import` tag.

The original project was developed by Vyacheslav Frolov and its contributors.
This Git repository was created to preserve the source and support possible
future maintenance.
